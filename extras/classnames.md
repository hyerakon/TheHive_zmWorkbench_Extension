# TheHive_zmWorkbench_Extension - Classnames

Generato da `Tools/make_extras.py` dai `config.cpp` della mod.

- Classe senza `scope` esplicito: scope del padre se e' della mod, altrimenti 2.
- Nei `types.xml` ci sono solo le classi scope 2 di CfgVehicles/CfgWeapons/CfgMagazines con prefisso The Hive,
  senza strutture, oggetti per l'editor, proxy e classi base. Valori dal server The Hive; le classi che sul server
  non hanno una voce sono messe a `nominal 0` (non spawnano).
